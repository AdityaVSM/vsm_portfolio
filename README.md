# Portfolio

Personal portfolio built with React, TypeScript and Vite.

## Develop

```bash
npm install
npm run dev
```

## Updating content

All content lives in `src/data/profile.ts`. Edit it to add or change experience, projects, skills, stats or links; the sections render whatever is there.

- Resume: replace `public/resume.pdf`.
- Styling: design tokens (colors, fonts, spacing) are at the top of `src/index.css`.
